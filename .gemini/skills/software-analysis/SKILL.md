# Software Analysis Skill

## Overview

This skill provides methodologies and workflows for analyzing software systems. It focuses on understanding existing code, identifying issues, and ensuring security and performance.

## Core Capabilities

### 1. Codebase Exploration
- Mapping system architecture and dependencies.
- Identifying entry points and critical paths.
- Understanding data flow and state management.

### 2. Debugging & Root Cause Analysis
- Systematic isolation of bugs.
- Analyzing stack traces and logs.
- Reproducing issues with minimal test cases.

### 3. Performance Analysis
- Identifying bottlenecks in execution time or memory usage.
- Analyzing algorithm complexity (Big O).
- Profiling resource usage (CPU, RAM, Network).

### 4. Security Auditing
- Identifying common vulnerabilities (OWASP Top 10).
- Checking for insecure dependencies.
- Reviewing authentication and authorization logic.
- Ensuring data privacy and secure storage.

## Workflow

1. **Information Gathering**: Use tools like `grep`, `glob`, and `read_file` to understand the code.
2. **Hypothesis Formation**: Formulate theories on the cause of the issue or the structure of the system.
3. **Verification**: Run tests, profilers, or static analysis tools to validate hypotheses.
4. **Reporting**: Summarize findings with actionable recommendations.
