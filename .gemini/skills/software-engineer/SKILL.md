# Software Engineer Skill

## Overview

This skill encapsulates core software engineering principles and methodologies. It is designed to assist in architectural decisions, logic implementation, and maintaining high code quality across any project.

## Core Principles

### 1. Clean Code & SOLID
- **S**ingle Responsibility: One class/function should have one reason to change.
- **O**pen/Closed: Software entities should be open for extension but closed for modification.
- **L**iskov Substitution: Subtypes must be substitutable for their base types.
- **I**nterface Segregation: Prefer many small interfaces over one large one.
- **D**ependency Inversion: Depend on abstractions, not concretions.

### 2. Design Patterns
- **Creational**: Singleton, Factory, Builder, Prototype.
- **Structural**: Adapter, Composite, Decorator, Proxy, Facade.
- **Behavioral**: Strategy, Observer, Command, State, Template Method.

### 3. Architectural Patterns
- Layered Architecture.
- Microservices vs. Monolith.
- Event-Driven Architecture.
- Domain-Driven Design (DDD).

### 4. Development Lifecycle
- Requirement analysis and technical specification.
- Test-Driven Development (TDD) and Behavior-Driven Development (BDD).
- Continuous Integration and Continuous Deployment (CI/CD).
- Peer reviews and collaborative development.

## Usage Guidelines

- Use this skill when asked to "design", "refactor", or "optimize" complex systems.
- Apply these principles when writing any code to ensure long-term maintainability.
- Consult this skill for choosing the right design pattern for a specific problem.
